# Сценарий демонстрации (4–5 минут)

Цель: за 4 минуты показать весь путь — от загрузки видео до ответа на вопрос по лекции,
и объяснить, почему это не «ещё один поиск по словам».

## За 10 минут до защиты

```powershell
.\start.bat
```

Дождитесь прогрева (в консоли `models are warm`, первые 3–4 минуты). Проверьте
`http://127.0.0.1:8000/api/health` — все пункты `ok`.

Войдите в заранее созданный аккаунт (или зарегистрируйтесь на странице входа).

Откройте библиотеку: одна готовая лекция уже должна быть. Если нет — загрузите
`videos_examples\пример_1.mp4` заранее (обработка 7,5-минутной лекции занимает ~4–6 минут).
Название можно не заполнять — оно сгенерируется по содержанию.

Проверьте импорт по ссылке: `+ Загрузить → По ссылке`. В форме заранее покажите выбор
приватности, группы, исходного языка, RU/EN-перевода, озвучки и GPU.

## 0:00–0:40 — Проблема

> «Лекции — это часы видео. Найти в них ответ можно только перемоткой, а поиск по названию
> не работает. Lectora индексирует смысл: вы спрашиваете словами — получаете момент в видео.»

Покажите библиотеку, карточки, статистику: сколько часов и смысловых фрагментов в индексе.

## 0:40–1:30 — Поиск по курсу

1. `Ctrl+K` — командная палитра.
2. Введите: **«формула объёма конуса»** (по смыслу, не по названию).
3. Enter — страница результатов: таймкоды, подсветка, релевантность, время ответа.
4. Клик по результату — плеер перематывается ровно на нужный момент, субтитры включаются.

Акцент: «Поиск идёт по смыслу: слова "объём" и "конус" в запросе могут стоять в другом
порядке, а в лекции звучать как "одна треть площади основания на высоту"».

## 1:30–2:15 — Внутри лекции и перевод

1. Плеер: нажмите на плашку **«0:00 Прямоугольный параллелепипед»** внизу слева — откроются
   главы лекции с таймкодами. Выберите «2:00 Правильные многогранники» — видео перематывается.
2. Нажмите полноэкранный режим: плашка глав и текущий таймкод остаются на месте.
3. На полосе прогресса видны засечки глав; под плеером — «карта лекции» с оранжевыми метками
   найденных фрагментов.
4. Ниже — **транскрипт по главам**: заголовки разделов с таймкодами, клик по любому
   предложению перематывает видео. Автопрокрутка по умолчанию выключена — включается
   кнопкой «Автопрокрутка».
5. Вкладка **«Поиск»** справа: введите **«площадь поверхности сферы»**, клик по результату —
   переход на момент.
6. В **«Настройки»** покажите единый выбор субтитров: выкл., исходный язык, перевод или
   два языка. Переключите «Оригинал» на русскую/английскую озвучку — громкость остаётся
   общей для выбранной дорожки.

## 2:15–2:55 — Конспект, структура и название

1. Вкладка **«Конспект»**: обзор лекции, ключевые термины, 5 глав с таймкодами.
2. Клик по разделу — переход к началу.
3. Обратите внимание на название лекции: мы загрузили файл `пример_3.mp4`, а в библиотеке
   появилось осмысленное имя, которое придумала модель по содержанию. Рядом с плеером —
   кнопка «Переименовать», если хочется поправить вручную.

## 2:55–3:30 — Вопросы по лекции

1. Вкладка **«Вопросы»**: **«Что такое прямоугольный параллелепипед?»**
2. Ответ + чипы-цитаты с таймкодами. Клик по цитате — переход к первоисточнику.
3. Показать, что ответ не выдуман: это фрагменты лекции.

## 3:30–4:20 — Личный кабинет, публичность и «Для Вас»

1. Откройте **«Мой кабинет»**: ручные группы, автокатегории и подкатегории, сортировка.
2. Покажите смену группы и статуса видео, публичность группы и ссылку на приватный материал.
3. Откройте **«Публичные видео»** → вкладка **«Для Вас»**.
4. Покажите профиль интересов: чипы тем, собранные из загруженных лекций и просмотров.
5. У карточек — причина рекомендации («Темы: …») и процент совпадения. Свои лекции в ленту
   не попадают.
6. Если профиль ещё пуст — лента собирается по популярности и свежести (холодный старт),
   интерфейс честно объясняет это и предлагает загрузить первую лекцию.

## 4:20–5:00 — Технологии и надёжность

* Whisper/Vosk → перевод DeepSeek → bge-m3 → PostgreSQL FTS → reranker → DeepSeek/Qwen.
* Рекомендации — материализованный профиль интересов, устойчивое к морфологии сопоставление
  тем и прозрачные причины выдачи.
* Очередь задач переживает перезапуск, прогресс по SSE, ошибки показываются человеческим языком.
* Локальный режим остаётся автономным; перевод и подробный облачный конспект включаются
  явно через DeepSeek API.

## Запасные ответы на вопросы жюри

**«Почему два движка ASR?»**
Whisper точнее и ускоряется CUDA, особенно для английского. Vosk остаётся лёгким полностью
локальным резервом для русского и работает даже без GPU.

**«Насколько быстро?»**
7,5 минут видео: ~2 минуты распознавания, ~30 секунд конспекта, поиск 2–3 секунды
(повторный — ~20 мс за счёт кэша реранка).

**«Что если модель недоступна?»**
Конспект и структура строятся экстрактивно, Q&A отдаёт релевантные фрагменты; интерфейс
честно помечает, что LLM не использовалась.

**«Масштабирование?»**
Очередь уже в БД (`SKIP LOCKED`), воркеры выносятся отдельным процессом; эмбеддинги
переезжают в pgvector, кэш — в Redis. Фронтенд и API не меняются.

**«Безопасность?»**
Белый список расширений, UUID-имена файлов, защита от path traversal, лимит размера,
`nosniff`, отсутствие исполняемого контента. Cookie-сессии с хешированными паролями,
проверка владельца лекции и группы. Для публичного развёртывания — TLS и reverse-proxy.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `health` показывает `llm.available=false` | `scripts\start_llm.ps1`, подождать 20 с |
| Поиск/загрузка отвечают 503 | проверить `data\logs\server.err.log` |
| Видео не проигрывается | открыть `/api/lectures/{id}/media` — должен отдаваться Range |
| Долгая обработка | включить Whisper GPU; для Vosk использовать профиль «быстрое» |
| Ошибка озвучки | повторить задачу: части кэшируются, временные сетевые ошибки повторяются автоматически |
